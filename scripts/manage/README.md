# Management Scripts

1-click scripts voor veelgebruikte taken (macOS).

## Gebruik

**Dubbelklik** op een `.command` bestand in Finder - opent automatisch in Terminal.

## Beschikbare Scripts

| Script | Beschrijving |
|--------|-------------|
| `dev.command` | Start de development server |
| `stop.command` | Stop alle draaiende dev servers |
| `build.command` | Build voor productie |
| `preview.command` | Preview de productie build |
| `typecheck.command` | Run TypeScript type checking |
| `clean.command` | Verwijder build artifacts en caches |
| `install.command` | Installeer npm dependencies |
| `scrape.command` | Scrape content van ru.nl |

## Alternatief: npm scripts

```bash
npm run dev        # Start dev server
npm run build      # Build voor productie
npm run preview    # Preview productie build
npm run typecheck  # Type check
```
